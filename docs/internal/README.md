# Internal working documents

These are working documents — shared project plans and dated code audits — kept in
the repository for the team but **not published** to the documentation site. The
`mkdocs.yml` at the repository root excludes this directory from the build
(`exclude_docs: internal/`), so nothing here is served or linked from the public
site.

What belongs here:

- project plans agreed with partners (`piano-wp2-wp3.md`) and improvement plans for
  parts of the repository (`piano-guida-scenario.md`);
- dated code audits and review notes (`audit-YYYY-MM-DD.md`);
- anything else that is a record of the work rather than documentation of the
  platform.

Documentation that explains how the platform works or how to use it — architecture,
scenarios, components, the KG and attack trees, the playground — belongs in
`docs/` (one level up), where it is published.
